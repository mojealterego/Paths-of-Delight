# Reguły zgody

1. Odpowiedzi prywatne A/B pozostają niewidoczne dla partnera.
2. Tylko `TAK + TAK` tworzy blind match.
3. Po blind match następuje osobny consent gate dla każdej osoby.
4. Aktywność zaczyna się wyłącznie po dwóch aktualnych zgodach.
5. `NIE`, `MOŻE`, `POMIŃ`, `PAUZA` i wycofanie zgody nie odbierają punktów i nie blokują progresu.
6. Niższy limit intensywności zawsze wygrywa.
7. Wyłączone prywatnie tagi eliminują kartę przed doborem.
8. Punkty mogą być przyznane za dobrowolne ukończenie neutralnej rundy, nigdy za sam akt wyrażenia zgody.
9. AI/rekomendacje nie mogą nadpisywać tych reguł.
